## 🇻🇳 Tiếng Việt

### Giới thiệu

Đây là kho lưu trữ source code các bài tập lập trình và tài liệu học tập trong quá trình học tại PTIT.

Các lời giải chủ yếu phục vụ mục đích học tập và tham khảo. Một số cách tiếp cận có thể chưa tối ưu về thời gian chạy, bộ nhớ hoặc cấu trúc chương trình.

### Cấu trúc kho lưu trữ

| Thư mục | Nội dung |
|---|---|
| [`C/`](C/) | Bài tập lập trình C, gồm code tổng hợp và bài nộp theo chủ đề |
| [`CPP/`](CPP/) | Bài tập lập trình C++ được phân loại theo chủ đề |
| [`TRR1/`](TRR1/) | Bài tập và tài liệu môn Toán rời rạc 1 |

### Nền tảng luyện tập

| Nền tảng | Liên kết |

### Cách tra cứu

- Mở thư mục tương ứng với ngôn ngữ hoặc môn học.
- Tiếp tục chọn thư mục chủ đề phù hợp.
- Sử dụng `Ctrl + F` để tìm mã bài hoặc tên bài khi cần.

### Tài liệu tham khảo

### Ghi chú

- Code được lưu trữ nhằm phục vụ học tập và tham khảo.
- Lời giải có thể chưa tối ưu hoặc có nhiều cách tiếp cận khác nhau.
- Hãy tự giải bài trước khi tham khảo source code.
- Tuân thủ quy định học thuật và quy định nộp bài của từng nền tảng.

## 🇬🇧 English

### About

This repository contains programming practice solutions and study materials collected during my studies at PTIT.

The solutions are intended for educational and reference purposes. Some approaches may not be optimal in terms of runtime, memory usage, or code structure.

### Repository Structure

| Directory | Contents |
|---|---|
| [`C/`](C/) | C programming exercises, including full code collections and topic-based submissions |
| [`CPP/`](CPP/) | C++ programming exercises organized by topic |
| [`TRR1/`](TRR1/) | Discrete Mathematics I exercises and study materials |

### Practice Platforms

| Platform | Link |

| Code PTIT | [Browse problems](https://code.ptit.edu.vn) |
| SPOJ PTIT | [Visit SPOJ PTIT](https://www.spoj.com/PTIT/status/) |

### How to Navigate

- Open the relevant programming language or subject directory.
- Browse the corresponding topic folder.
- Use `Ctrl + F` to search for a problem ID or title when needed.

### References

### Notes

- Solutions may not be optimal, and alternative approaches may exist.
- Try solving each problem independently before referring to the source code.
- Follow the academic integrity policies and submission rules of each platform.
